Quick tips

  • Start linear pressure curve, then add gentle S-shape.
  • Windows Ink: try ON first; if pressure fails in an app, try OFF + WinTab.
  • Map to one monitor for precision; switch when needed.

Recommended settings by app

Photoshop

  • Windows Ink: try ON; if pressure fails or lags, turn Ink OFF and enable WinTab in PS.
  • Brush: start with minimal S-curve; smoothing 5–10 for line art.
  • Performance: enable GPU; disable heavy overlays while drawing.
  • Shortcuts: map pen button to Alt (eyedropper) or Space (pan).

Illustrator

  • Windows Ink: ON recommended; adjust pressure via brush settings.
  • Brush fidelity: lower smoothing for faster response.
  • GPU Performance: ON; test Real-Time Drawing & Editing.
  • Pen tilt: map for calligraphic brushes if supported.

Clip Studio Paint

  • Windows Ink: ON by default; switch to WinTab only if pressure fails.
  • Stabilization: 10–20 for smooth lines without heavy lag.
  • Pressure curve: slightly lighter at the start for tapers.
  • Tablet settings: ensure correct monitor mapping per workspace.

Pressure curve presets

Line art (inking)

Gentle S-curve. Light initial pressure for clean tapers; keep mid-high linearity to avoid sudden jumps.

Painting (soft shading)

Slightly flatter early curve to broaden mid-tones. Increase flow/opacity dynamics in app brushes.

3D sculpt/texturing

More linear curve for predictable depth; map a pen button to Alt/Rotate for quick navigation.

Windows Ink vs WinTab

When to use Windows Ink

Start with Ink ON. Many modern apps use Ink for native pen input. If you see pressure inking correctly, keep it on.

When to switch to WinTab

If pressure disappears, double-click misfires, or lag occurs, turn Ink OFF in Wacom Tablet Properties and enable WinTab in the app (if available). Restart the app after changing.
