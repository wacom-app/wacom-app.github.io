How to Install and Set Up Wacom on Windows 11/10

Follow this quick guide to install the official Wacom Tablet Driver for Windows, configure essentials, and get pen pressure working fast.

Download Driver (Windows) Troubleshoot

Direct from cdn.wacom.com • Free • No wrappers

TL;DR Install in 6 steps

  1. Download the driver.
  2. Close drawing apps.
  3. Run installer as Administrator.
  4. Follow prompts.
  5. Restart Windows.
  6. Open Wacom Tablet Properties and configure.

Clean installation (recommended)

1) Download

Use the official CDN link: WacomTablet_6.4.13-4.exe.

2) Close apps

Quit Photoshop, Illustrator, Clip Studio, ZBrush, etc., to prevent conflicts.

3) Run as Admin

Right-click the installer → Run as administrator. This ensures services can register.

4) Follow prompts

Accept license, keep default options unless you know you need changes.

5) Restart

Restart Windows to load the Wacom service and complete setup.

6) Configure

Open Wacom Tablet Properties. Test pressure, set pen buttons, map to monitor, and tune Windows Ink.

Windows Ink & app tips

When Ink helps

Windows Ink enables native pen behavior in many apps. Try with Ink on first. If pressure fails in Photoshop, toggle Ink off in Wacom Tablet Properties and in app preferences.

Pressure curve

Use a gentle S-curve for illustration, a flatter curve for inking. You can fine-tune per app in brush settings.

Mapping & monitors

Map the tablet to your main display. For multi-monitor setups, consider per-app mapping for comfort.

Services restart

If pen stops responding, restart the Wacom service or reboot. See Troubleshoot for quick fixes.
