Install guide

How to install Wacom driver on Windows — step-by-step guide

Install Wacom Tablet Driver 6.4.13-4 on Windows 10 and 11. Covers pre-install cleanup, running as admin, reboot, tablet connection and post-install verification.

Always uninstall any previous Wacom driver before installing a new one. Skipping this step is the most common cause of post-install issues.
Before you start

Pre-install checklist

  • Unplug your Wacom tablet from the PC before starting
  • Close all open applications, especially Photoshop, Clip Studio and browsers
  • Note: you need administrator rights to install the driver
Installation

Step-by-step install guide

  • 1

    Uninstall existing Wacom driver

    Control Panel → Programs → Uninstall a program → find Wacom Tablet or Wacom Driver → Uninstall. If prompted to restart, do so before continuing.

  • 2

    Download driver 6.4.13-4

    Get WacomTablet_6.4.13-4.exe from the download page. Save it to your Desktop or Downloads folder.

  • 3

    Run as Administrator

    Right-click the installer → Run as administrator. Accept the UAC prompt. The setup wizard opens — follow the prompts and accept the license agreement.

  • 4

    Reboot when prompted

    The installer will ask you to restart. Click Restart Now. Do not skip this — the driver does not fully activate until after a reboot.

  • 5

    Connect your tablet

    After reboot, plug in your Wacom tablet via USB. Windows will detect it automatically. The Wacom icon should appear in the system tray within 10-20 seconds.

  • 6

    Verify the install

    cmd.exe
    # Check Wacom service is running:
    C:\> sc query WTabletServicePro
    STATE : 4 RUNNING

    Open Wacom Tablet Properties (system tray icon or Start menu) and move your pen — you should see the cursor track the pen. Test pressure in the online pressure test.

Post-install

If something does not work after install

Pen moves cursor but pressure not working
Driver installed but app not configured for WinTab/Windows Ink
Check app brush settings and see pressure guide
Wacom icon not in system tray after reboot
Service did not start automatically
services.msc → Wacom Professional Service → Start
Tablet detected but pen does not respond
USB connection or tablet firmware issue
Try different USB port, unplug/replug tablet
FAQ

Install questions

Can I install without uninstalling the old driver?
Technically yes, but it is strongly not recommended. Old driver remnants frequently cause conflicts resulting in pressure not working, tablet not detected, or Wacom Properties not opening. Always do a clean uninstall first.
The installer says "A previous installation was detected"
The uninstaller left some files behind. Use the Wacom Tablet Utility to remove them: look for it in C:\Program Files\Tablet\Wacom\32\ or download the separate cleanup utility from wacom.com. Then retry the install.
Do I need to install drivers for each tablet separately?
No. One driver install supports all Wacom tablets. If you have both an Intuos and a Cintiq, install the driver once and configure each tablet in Wacom Tablet Properties.
