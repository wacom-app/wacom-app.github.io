Wacom Windows Ink — enable, disable & fix per-app guide

Windows Ink vs WinTab for Wacom on Windows. Photoshop CC needs Windows Ink ON, Krita needs it OFF. How to toggle and configure per-app.

What is Windows Ink?

Windows Ink — two tablet input APIs on Windows

Windows has two APIs for pen tablets: WinTab (older, industry standard since the 1990s) and Windows Ink (Microsoft's newer API, introduced with Windows 8). Wacom supports both — you choose which one to use in Wacom Tablet Properties.

How to enable or disable Windows Ink

  • 1

    Open Wacom Tablet Properties

    Right-click the Wacom icon in the system tray → Wacom Tablet Properties.

  • 2

    Click the Pen tab

    Select the Pen tab at the top of the Wacom Tablet Properties window.

  • 3

    Check or uncheck "Use Windows Ink"

    The checkbox is at the bottom of the Pen tab. Check it to enable Windows Ink, uncheck to use WinTab (legacy) mode.

  • 4

    Restart your app

    Close and reopen your drawing application. The change does not take effect in a running application.

If you use multiple apps with different requirements (e.g. Photoshop CC and Krita), you will need to toggle this setting when switching between them, unless the app has its own API override setting.
App-specific fixes

Windows Ink settings by application

Photoshop CC 2019+ — enable Windows Ink

Adobe switched Photoshop to Windows Ink API in 2019. Steps:

  1. Enable Windows Ink in Wacom Tablet Properties (see above)
  2. In Photoshop: Edit → Preferences → Performance → Advanced Settings → Drawing Mode: Basic
  3. Restart Photoshop
Krita — disable Windows Ink

Krita works better with WinTab (Windows Ink OFF). Steps:

  1. Disable Windows Ink in Wacom Tablet Properties
  2. In Krita: Settings → Configure Krita → Tablet Settings → select WinTab
  3. Restart Krita
Clip Studio Paint — configure in app

Clip Studio Paint has its own tablet API setting. Go to: File → Preferences → Tablet → select Wintab or Windows Ink to match your Wacom setting. Restart CSP after changing.

Blender — disable Windows Ink

Blender uses WinTab by default and can have issues with Windows Ink. Disable Windows Ink in Wacom Tablet Properties. In Blender: Edit → Preferences → Input → Tablet API: set to WinTab.

FAQ

Windows Ink questions

Windows Ink is enabled but pressure still not working in Photoshop
Check the Drawing Mode: Edit → Preferences → Performance → Advanced Settings. Set Drawing Mode to Basic (not Advanced or Normal). Also make sure you restarted Photoshop after enabling Windows Ink.
I do not see the Windows Ink checkbox in Wacom Tablet Properties
This option may not be visible if the tablet is not connected or the driver is not fully loaded. Ensure your Wacom tablet is plugged in and the Wacom service is running before opening Wacom Tablet Properties.
