Extended FAQ

Wacom Windows FAQ — driver, pressure & app questions

Extended FAQ for Wacom on Windows. Driver install, pen not working, pressure fixes for Photoshop, Krita and Clip Studio, tablet detection and Windows Ink toggle.

Driver & install

Driver & install

What is the latest Wacom driver for Windows?
Wacom Tablet Driver 6.4.13-4 is the latest stable release for Windows 10 and 11. Download from the download page.
Do I need to uninstall the old driver first?
Yes. Always uninstall the existing driver before installing a new version. Installing over an existing driver causes conflicts. See install guide.
Driver install fails or freezes
Make sure you right-click → Run as Administrator. Disable antivirus temporarily. If it still fails, try the clean install procedure.
Does Wacom work on Windows 11?
Yes, fully. Driver 6.4.13-4 is compatible with Windows 11. After upgrading from Windows 10, do a clean uninstall/reinstall. See Windows 11 guide.
Pen & pressure

Pen & pressure

Pen not working at all after install
Restart the Wacom service: net stop WTabletServicePro && net start WTabletServicePro. If still not working, see pen not working guide.
Pen pressure not working in Photoshop
Enable Windows Ink in Wacom Tablet Properties → Pen tab. In Photoshop: Preferences → Performance → Advanced → Drawing Mode: Basic. Restart PS. See Photoshop guide.
Pen pressure not working in Krita
Disable Windows Ink in Wacom Tablet Properties. In Krita: Settings → Configure Krita → Tablet → WinTab. See pressure fix guide.
How to test pen pressure online?
Use the online pressure test tool on this site. Draw on the canvas to see live pressure and tilt readings.
Detection

Detection

Tablet not detected after plugging in
Try a different USB port (USB 2.0 directly on motherboard). Restart Wacom service. See not detected guide.
Tablet works then disconnects randomly
Disable USB Selective Suspend: Power Options → Change advanced power settings → USB Settings → Disabled. See detection guide.
Apps

Apps

Windows Ink on or off?
Depends on your app. Photoshop CC 2019+: ON. Krita, Blender: OFF. CSP: configure in app. See Windows Ink guide.
Wacom works in one app but not another
Different apps use different input APIs. Toggle Windows Ink in Wacom Tablet Properties and match the app's own tablet settings. See best settings.
