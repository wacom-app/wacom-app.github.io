Windows 11 guide

Wacom on Windows 11 — compatibility, drivers & known issues

Wacom driver 6.4.13-4 is fully compatible with Windows 11. This guide covers tablet compatibility, issues after upgrading from Windows 10, and fixes for common Windows 11 problems.

Wacom driver 6.4.13-4 is fully compatible with Windows 11. Most Wacom tablets work out of the box after a clean install of this driver version.

Upgrade guide

Upgrading from Windows 10 to 11 with Wacom

  • 1

    Before upgrading

    Note your current Wacom settings (tablet area, pen buttons, pressure curve). Take a screenshot of Wacom Tablet Properties. The upgrade will likely reset your settings.

  • 2

    After the Windows 11 upgrade

    Uninstall the Wacom driver completely via Control Panel. Reboot. Then reinstall driver 6.4.13-4 as Administrator. Do not skip the uninstall step.

  • 3

    Reconfigure your settings

    Reopen Wacom Tablet Properties and restore your preferred settings: tablet area, pen buttons, pressure curve and Windows Ink preference.

FAQ

Windows 11 questions

Wacom worked on Windows 10 but not after upgrading to 11
This is the most common issue. Uninstall the driver completely, reboot, then reinstall driver 6.4.13-4 fresh. The Windows 11 upgrade sometimes corrupts the Wacom USB driver entries. A clean reinstall almost always fixes this.
Windows 11 shows "Driver not digitally signed" warning
This should not happen with the official driver from wacom.com or from this site. If you see this warning, the file may be corrupt or from an unofficial source. Download the driver again from the official source and verify the digital signature in file Properties.
USB selective suspend causing tablet to disconnect
Windows 11 sometimes aggressively suspends USB devices. Go to Power Options → Change plan settings → Change advanced power settings → USB Settings → USB selective suspend setting → set to Disabled.
