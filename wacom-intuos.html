Intuos guide

Wacom Intuos setup on Windows — driver install & configuration guide

Set up Wacom Intuos (CTL-4100, CTL-6100, PTH series) on Windows 10 and 11. Covers driver install, USB and Bluetooth connection, model comparison and pressure configuration.

Wacom Intuos is one of the most popular entry-level tablets. Driver 6.4.13-4 supports all Intuos generations: Intuos Small, Medium and Large (CTL-4100, CTL-6100, CTH series).
Setup

Set up Wacom Intuos on Windows

  • 1

    Download and install the driver

    Get WacomTablet_6.4.13-4.exe from the download page. Run as Administrator and reboot when prompted.

  • 2

    Connect Intuos via USB

    Plug in the Intuos USB cable. For wireless Intuos: insert the Bluetooth receiver into a USB port. The Wacom tray icon appears when connected.

  • 3

    Install Wacom Desktop Center (optional)

    The installer may prompt you to install Wacom Desktop Center — a companion app for firmware updates and settings. This is optional but recommended for keeping the tablet firmware current.

  • 4

    Configure pen and tablet

    Open Wacom Tablet Properties. Set your preferred tablet area, pen pressure curve, and button assignments. See best settings guide.

Bluetooth setup

Connect Intuos via Bluetooth

Some Intuos models support Bluetooth. To connect wirelessly:

  • For Bluetooth USB dongle models: insert the Bluetooth receiver into a USB port — it pairs automatically
  • For standard Bluetooth models: hold the tablet button until the LED blinks, then pair in Windows Settings → Bluetooth
  • Install the driver before attempting Bluetooth pairing
FAQ

Intuos questions

Intuos not detected on Windows 11
Try a different USB port (USB 2.0 directly on motherboard). Reinstall driver 6.4.13-4 as Administrator. See tablet not detected guide.
Intuos pen pressure not working in Photoshop
Enable Windows Ink: Wacom Tablet Properties → Pen → Use Windows Ink. Then in Photoshop: Edit → Preferences → Performance → Advanced → Drawing Mode: Basic. Restart Photoshop.
Does Intuos support tilt?
Basic Intuos (CTL-4100/6100) does not support tilt. Intuos Pro (PTH series) supports tilt up to ±60 degrees. Check your specific model specs on wacom.com.
