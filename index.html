Quick install

Install Wacom driver in 3 steps

  • 1

    Uninstall old driver

    Control Panel → Programs → uninstall any existing Wacom driver. Reboot your PC.

  • 2

    Run installer as Administrator

    Right-click WacomTablet_6.4.13-4.exe → Run as administrator. Follow the wizard and reboot when prompted.

  • 3

    Connect tablet and test

    Plug in your Wacom tablet via USB. Open Wacom Tablet Properties from the system tray and test pen pressure. See the online pressure test.

Quick answers

Common questions

Pen not working after install?
Try restarting the Wacom service: Win+R → services.msc → find Wacom Professional Service → Restart. If that does not help, see the pen not working fix guide.
Does this driver work on Windows 11?
Yes. Driver 6.4.13-4 is compatible with Windows 11. See the Windows 11 compatibility guide for known issues and fixes.
Which Wacom tablets does this driver support?
The standard Wacom driver supports Intuos (all generations), Cintiq, Cintiq Pro, Wacom One (pen display), and Bamboo. Wacom One (basic CTL-472/672) may use a different lightweight driver — check Wacom One guide.
