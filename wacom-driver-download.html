FAQ

Download questions

Which driver do I need for my Wacom model?
Driver 6.4.13-4 covers all current Wacom tablets: Intuos, Intuos Pro, Cintiq, Cintiq Pro, Wacom One (DTC), and Bamboo. If you have a very old model (Bamboo Fun, pre-2012 Intuos), check wacom.com for a legacy driver.
32-bit vs 64-bit driver?
Driver 6.4.13-4 is a 64-bit installer that works on all 64-bit Windows 10 and 11 systems. There is no separate 32-bit version needed — 64-bit Windows handles both 32-bit and 64-bit applications.
Do I need a different driver for Wacom One vs Intuos Pro?
No. The same driver 6.4.13-4 supports both Wacom One and Intuos Pro. Install it once and both tablets will work. Configure each in Wacom Tablet Properties separately.
