FAQ

Wacom Windows FAQ — all common questions answered

Quick answers to the most common Wacom questions on Windows: driver download, pen pressure, tablet detection, Windows Ink and app-specific setup.

Download & install

Download & install

What is the latest Wacom driver version?
Wacom Tablet Driver 6.4.13-4 is the latest stable release for Windows 10 and 11. Download it from the download page.
Which Wacom tablets does driver 6.4.13-4 support?
Intuos (all generations CTL/CTH), Intuos Pro (PTH), Cintiq (DTK/DTH), Cintiq Pro, Wacom One pen display (DTC-133), and Wacom One basic (CTL-472/672). Older Bamboo models may require a legacy driver from wacom.com.
Do I need to uninstall the old driver before installing?
Yes, always. Installing over an existing driver frequently causes pressure issues, detection problems, and corrupted settings. Uninstall via Control Panel → Programs first, reboot, then install the new driver.
Does Wacom work on Windows 11?
Yes. Driver 6.4.13-4 is fully compatible with Windows 11. If upgrading from Windows 10, do a clean uninstall and reinstall of the driver after the upgrade. See Windows 11 guide.
Pen & pressure

Pen & pressure

Pen pressure not working in Photoshop
Photoshop CC 2019+ requires Windows Ink to be enabled. Open Wacom Tablet Properties → Pen tab → check Use Windows Ink. Restart Photoshop. See Photoshop guide.
Pen pressure not working in Krita
Krita works best with Windows Ink disabled. Uncheck Windows Ink in Wacom Tablet Properties. In Krita: Settings → Configure Krita → Tablet settings → select WinTab. See pressure fix guide.
How to test pen pressure online?
Use the built-in pressure test tool on this site. Draw on the canvas to see pressure levels and tilt in real time.
Pen cursor jumps or is inaccurate
Recalibrate the pen: Wacom Tablet Properties → Calibrate tab. Also check the tablet area mapping in the Mapping tab — enable Force Proportions to avoid stretching.
Detection & connection

Detection & connection

Tablet not detected after plugging in
Try a different USB port (preferably USB 2.0 directly on the motherboard, not a hub). Restart the Wacom service: net stop WTabletServicePro && net start WTabletServicePro. See not detected guide.
Wacom works on USB but not Bluetooth
Bluetooth support varies by model. Ensure Bluetooth is enabled and the tablet is in pairing mode. For Intuos Pro: hold the touch ring button until the LED flashes. Install the driver before attempting Bluetooth pairing.
Wacom keeps disconnecting
Disable USB Selective Suspend: Power Options → Change plan settings → Change advanced power settings → USB Settings → USB selective suspend → Disabled.
Apps & compatibility

Apps & compatibility

Should I use Windows Ink on or off?
Depends on the app. Photoshop CC 2019+: ON. Krita, Blender, older Photoshop: OFF. Clip Studio Paint: either (configure in CSP). See Windows Ink guide and best settings.
Wacom not working in one specific app
The app may use a different input API. Try toggling Windows Ink in Wacom Tablet Properties. Also check the app's own tablet settings — many apps have a dedicated tablet input option in preferences.
