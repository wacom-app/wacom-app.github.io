Frequently asked questions

Is this the official Wacom driver download?
Yes. Our buttons link directly to Wacom's CDN (cdn.wacom.com). We never host or wrap installers.
Does it work on Windows 11?
Yes. Current drivers support Windows 10/11. See Windows 11 notes for tips.
How do I install the driver?
Close drawing apps, run the installer as Administrator, follow prompts, then restart Windows. Full install guide.
How do I clean reinstall?
Uninstall the Wacom driver → reboot → download the latest installer → run as Admin → reboot again.
Windows Ink: on or off?
Start with Ink ON. If pressure fails or feels laggy in an app, try Ink OFF and use WinTab in that app. See Best Settings.
Pen pressure is missing in my app
Restart the Wacom service, toggle Windows Ink, make sure only one tablet driver is installed, and check app brush prefs. Try our Pressure Test.
Tablet not detected or connects intermittently
Use a direct USB port (avoid hubs), try a different cable/port, reinstall the driver, and check Device Manager for duplicate HID entries.
How do I calibrate a Cintiq/display tablet?
Map to the correct monitor first, then use Calibrate in Wacom Tablet Properties. Test at 100% Windows scaling to diagnose offsets.
Where can I find official release notes and support?
Visit wacom.com/support for release notes and model-specific help.
Is this site free? Do you bundle software?
This site is free. We link only to the official Wacom installer. No bundles, no registration.
