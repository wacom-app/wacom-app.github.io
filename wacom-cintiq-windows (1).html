Cintiq guide

Wacom Cintiq setup on Windows — display, mapping & calibration guide

Set up Wacom Cintiq (16, 22, Pro) on Windows 10 and 11. Connect HDMI/USB, configure display mapping, calibrate pen and fix common Cintiq-specific issues.

Cintiq pen displays are fully supported by driver 6.4.13-4 on Windows 10 and 11. The setup involves both a display connection (HDMI/DisplayPort) and a USB connection for pen input.
Connection

Connect Cintiq to Windows

ModelVideo connectionPower/Data
Cintiq 16 (DTK-1660)HDMIUSB-A to PC
Cintiq 22 (DTK-2260)HDMIUSB-A to PC
Cintiq Pro 13/16 (DTH)USB-C (single cable)USB-C to PC
Cintiq Pro 24/27 (DTH)HDMI or DisplayPortUSB-A + power adapter

Always install the driver before connecting the Cintiq for the first time. Run the installer as Administrator and reboot, then connect the display.

Setup

Configure Cintiq on Windows

  • 1

    Set as extended display

    Press Win+P → select Extend. Do not use Duplicate — the pen mapping will be wrong. In Display Settings, position the Cintiq display to match its physical position relative to your main monitor.

  • 2

    Map pen to Cintiq display

    Wacom Tablet Properties → Mapping tab → Current Display: select the Cintiq display from the dropdown. Enable Force Proportions.

  • 3

    Calibrate the pen

    Wacom Tablet Properties → Calibrate tab → Calibrate. Tap each target with your pen tip at the angle you normally hold it. Calibrate seated at your normal working distance.

  • 4

    Set display resolution and scaling

    Right-click desktop → Display settings. Set the Cintiq to its native resolution. Avoid Windows scaling percentages other than 100% — scaling can cause pen offset issues.

Common issues

Cintiq-specific issues on Windows

Pen cursor is offset from pen tip
Display scaling or calibration issue
Set display scaling to 100%, then recalibrate
Cintiq display detected but pen not working
USB cable not connected or Wacom service not running
Check USB connection, restart WTabletServicePro service
Touch not working on Cintiq Pro
HID touch driver disabled or conflict
Device Manager > HID-compliant touch screen > Enable
ExpressKeys not responding
Wacom Desktop Center needs update or driver issue
Update Wacom Desktop Center, restart service
FAQ

Cintiq questions

Pen works but cursor appears on the wrong monitor
The mapping is set to the wrong display. Open Wacom Tablet Properties → Mapping → Current Display → select your Cintiq specifically. If the Cintiq is not listed, check that it is recognised as a separate display in Windows Display Settings.
Cintiq display works but no pen pressure in Photoshop
Enable Windows Ink: Wacom Tablet Properties → Pen → Use Windows Ink. In Photoshop: Preferences → Performance → Advanced → Drawing Mode: Basic. Restart Photoshop.
Cintiq goes to sleep and does not wake
Disable USB selective suspend: Power Options → Change plan settings → Change advanced power settings → USB Settings → USB selective suspend → Disabled. Also check the display sleep settings.
